# 🏋️ FitLog

FitLog is a workout tracking web app where users can browse a workout library, build a daily plan, save favorite exercises, and track their progress — minutes trained, calories burned, and exercises completed — all in one clean dashboard.

**Train hard, log honest.**

🔗 **Live Link:** [https://a06-fit-log.vercel.app/](https://a06-fit-log.vercel.app/)
📦 **GitHub Repository:** [https://github.com/mehedynoman11/a06-fit-log](https://github.com/mehedynoman11/a06-fit-log)

---

## 🚀 Technologies Used

- **Next.js** (App Router) — React framework for routing and rendering
- **TypeScript** — static typing across components and context
- **Tailwind CSS** — utility-first styling
- **DaisyUI** — Tailwind component library (tabs, buttons, cards)
- **React Context API** — global state management for workouts, saved items, and active tab
- **React Icons** — icon set for UI elements (clock, star, check, etc.)
- **Vercel** — deployment and hosting

---

## ✨ Features

- 📋 **Today's Plan** — view and manage the workouts scheduled for the day
- ⭐ **Saved Workouts** — save favorite exercises from the library to revisit later
- 📊 **Live Stats Dashboard** — dynamically calculated totals for:
  - Total exercises
  - Total minutes
  - Total calories burned
- ✅ **Mark as Done** — track completed workouts in real time
- 🔍 **Workout Details** — view exercise info including equipment, duration, calories, and rating
- 📱 **Fully Responsive Design** — optimized layout across mobile, tablet, and desktop
- ⚡ **Global State with Context API** — shared workout, saved list, and active tab state across the app

## 🛠️ Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
